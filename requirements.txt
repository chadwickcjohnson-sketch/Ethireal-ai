# Ethireal AI

Automation in full.

Ethireal AI is an AI-native business automation platform designed to help founders, executives, teams, and operators automate the real work of running a business. It connects AI orchestration, workflow automation, natural-language task execution, business context, and operational reporting into one operational layer.

This repository now defines a working foundation for a full operational workflow: orchestration, automation, task execution, workflow templates, and a service-ready architecture for scaling into a business product.

## Product vision

Ethireal AI turns fragmented business operations into a cohesive execution system. It supports:
- executive briefing and leadership workflows
- sales pipeline automation
- support triage and response flows
- internal operations coordination
- reporting, summaries, and action tracking
- intelligent business process orchestration

## Quick start

### 1) Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

### 2) Install dependencies

```bash
pip install -r requirements.txt
```

### 3) Run the API

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 4) Test the health endpoint

```bash
curl http://localhost:8000/health
```

## API overview

### Health

```bash
GET /health
```

### List available workflows

```bash
GET /workflows
```

### Run a workflow

```bash
POST /workflows/executive_brief
{
  "owner": "ceo",
  "context": {
    "team": "leadership",
    "business_focus": "growth and efficiency",
    "priorities": ["pipeline", "operations", "customer retention"]
  }
}
```

### Get workflow status

```bash
GET /workflows/{workflow_id}/status
```
